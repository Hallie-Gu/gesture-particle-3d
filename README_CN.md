# 手势控制 3D 粒子系统

这是一个在浏览器中运行的交互式 3D 粒子项目。Three.js 负责渲染粒子场景，MediaPipe Hands 通过摄像头识别一只手，并将手掌张合和移动映射为粒子动画。

项目使用原生 Web 技术开发，无需安装项目依赖，也不需要 API Key；在本地通过开发服务器即可运行。

## 主要功能

- 实时渲染 3D 粒子和发光星空背景
- 通过摄像头追踪一只手
- 张开或握紧手掌，控制粒子展开和聚拢
- 左右、上下移动手掌，控制粒子形态旋转
- 四种粒子预设，并支持平滑切换
- 基础颜色和粒子密度控制
- 镜像显示且可以调整大小的摄像头预览
- 全屏显示，并自动同步按钮状态
- 未检测到手时缓慢自动旋转

## 技术栈

- HTML
- CSS
- JavaScript
- Three.js `0.160.0`
- MediaPipe Hands `0.4.1675469240`

Three.js 和 MediaPipe Hands 从 jsDelivr 加载，因此页面加载时需要网络连接。

## 本地运行方法

1. 使用 VS Code 打开项目文件夹。
2. 在 VS Code 中安装 **Live Server** 扩展。
3. 在资源管理器中右键单击 `index.html`。
4. 选择 **Open with Live Server**。
5. 浏览器打开页面后，允许摄像头权限。

页面地址应以 `http://localhost` 或 `http://127.0.0.1` 开头。

> 不要双击 `index.html`，也不要通过 `file://` 地址直接打开。应用需要安全的本地运行环境才能申请摄像头权限；使用这种方式打开时，页面会显示错误提示。

## 摄像头权限说明

应用只申请视频权限，不会申请麦克风权限。授权成功后，左下角会显示镜像摄像头画面。请将一只手完整放入画面，即可开始控制粒子。

如果之前拒绝了权限，请点击浏览器地址栏旁边的站点权限图标，将摄像头权限改为**允许**，然后点击页面中的**重新尝试摄像头**。

拖动摄像头预览框的顶部、右侧或右上角，可以调整预览框大小。

## 手势操作说明

| 手势或动作 | 效果 |
| --- | --- |
| 张开手掌 | 粒子完全向外散开。 |
| 握紧手掌 | 粒子聚拢并恢复为当前选择的完整形态。 |
| 手掌保持半开 | 保持上一次的展开或收拢状态，避免状态频繁跳动。 |
| 手掌左右移动 | 绕 Y 轴旋转粒子形态；旋转跟随手掌移动，手停止后旋转也会停止。 |
| 手掌上下移动 | 绕 X 轴倾斜粒子形态。 |
| 手移出画面 | 场景恢复缓慢自动旋转。 |

系统只追踪一只手，并根据识别到的手部关键点判断手掌张合程度和移动方向。

## 四种粒子预设

可以在控制面板中选择以下四种程序生成的粒子形态：

- **星云**：五条旋臂组成的云状结构
- **烟花**：多个球形爆发和拖尾组成的形态
- **土星**：由粒子球体和环带组成的行星
- **花朵**：七片花瓣组成的层叠形态

切换预设时，现有粒子会平滑变形为新的排列。

## 颜色和粒子密度控制

- **基础颜色：** 使用颜色选择器设置起始色相。显示颜色还会随着模型旋转和动画时间逐渐变化。
- **粒子密度：** 使用滑块选择 3,000 到 6,000 个粒子，步长为 500，默认值为 3,500 个粒子。

调整密度后，程序会根据当前预设重新创建粒子几何体。

## 全屏功能

点击右下角的全屏按钮，可以进入或退出全屏模式。也可以按 `Esc` 退出全屏；全屏状态变化后，按钮文字会自动更新。

## 常见问题

### 页面空白或 3D 场景没有显示怎么办？

- 确认地址以 `http://localhost` 或 `http://127.0.0.1` 开头，而不是 `file://`。
- 按 `Ctrl + F5` 忽略浏览器缓存并重新加载。
- 按 `F12` 打开浏览器开发者工具，在 Network（网络）面板中确认 `style.css` 和 `main.js` 加载成功。
- 确认浏览器已启用硬件加速，并暂时关闭可能阻止 WebGL 或脚本运行的扩展。

### 摄像头权限被拒绝或没有画面怎么办？

- 在浏览器的站点权限设置中，允许当前本地站点使用摄像头。
- 关闭可能正在独占摄像头的会议、录屏或其他软件。
- 点击页面中的**重新尝试摄像头**。
- 在 Windows 中检查“设置 > 隐私和安全性 > 摄像头”，允许桌面应用访问摄像头。
- 建议使用最新版 Google Chrome 或 Microsoft Edge，以获得更好的兼容性。

### Three.js、MediaPipe 或手部模型加载失败怎么办？

项目需要从 `cdn.jsdelivr.net` 下载脚本和 MediaPipe 模型文件。请检查网络连接，确认安全软件或代理没有拦截该域名，然后按 `Ctrl + F5` 重新加载页面。

### 为什么粒子会自动旋转？

最近没有检测到手时，自动旋转是正常的备用状态。将一只手完整放入摄像头画面，即可恢复手势控制。
